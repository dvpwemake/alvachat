# Admin decision — name + sequence

**Now:** keep building the **web app** (`meetup-web/`). Working title in the UI: **Meet50** (internal only).  
**Later:** Plan 2 (native iOS / CloudKit) starts **only after** admin (1) approves this web app and (2) picks a public name. Plan 2 must reuse the same brand, same nine functions, same API contracts — not a second product.

Do not ship Meet50, Meetup, Concur, Clink, Radius, Fifty, or any Tinder-rhyme as the public name.

Pick one. We rebrand the web app, then Plan 2 uses that name.

## Sequence (locked)

1. Finish / iterate the **web app** until admin says approved.  
2. Admin picks **one** name from the five (or rejects all and we mint a new five).  
3. Rebrand web, file the mark (9 / 42 / 45).  
4. **Then** Plan 2: native iOS, CloudKit, same nine functions, same flows as the approved web app.

Web remains the source of truth for product rules. Plan 2 is a client port, not a redesign.
